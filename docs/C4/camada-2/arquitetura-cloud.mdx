## Introdução

A AWS proporciona uma plataforma escalável, flexível e segura que permite o desenvolvimento e a implementação de aplicações robustas. Com a AWS, é possível reduzir custos operacionais, melhorar a performance e a disponibilidade das aplicações, e se beneficiar de uma vasta gama de serviços gerenciados que facilitam a gestão de infraestrutura e serviços.

## Componentes da Arquitetura

1. **App Angular**: Interface do usuário hospedada no S3 e distribuída pelo CloudFront.
2. **Amazon S3**: Armazenamento de objetos estáticos e recursos de front-end.
3. **Amazon CloudFront**: Distribuição de conteúdo global, melhorando a latência.
4. **Amazon Cognito**: Gerenciamento de autenticação e autorização dos usuários.
5. **AWS WAF**: Firewall para proteção contra ameaças e ataques web.
6. **AWS Shield**: Proteção contra ataques DDoS.
7. **Amazon Route 53**: Gerenciamento de DNS para roteamento eficiente de tráfego.
8. **API Gateway**: Interface para chamadas de API, gerenciando tráfego de requisições.
9. **Network Load Balancer**: Distribui o tráfego de rede entre os serviços.
10. **Amazon EKS (Cluster)**: Orquestração de contêineres, gerenciando a execução dos microserviços.
11. **Amazon RDS**: Banco de dados relacional para armazenamento persistente.
12. **AWS Backup**: Automação de backups e recuperação de dados.
13. **AWS Secrets Manager**: Gerenciamento seguro de credenciais e informações sensíveis.
14. **Amazon SQS**: Serviço de fila de mensagens para desacoplar componentes do sistema.
15. **Amazon SNS**: Serviço de notificação para envio de mensagens.
16. **Amazon CloudWatch**: Monitoramento e observabilidade das aplicações e serviços.
17. **Grafana**: Visualização e análise de dados de monitoramento.
