# Política de Privacidade

## Coleta e Uso de Dados
Coletamos dados pessoais como nome, email, histórico médico e informações de pagamento. Estes dados são utilizados para:

- Gerenciamento de contas de usuários.
- Agendamento de consultas médicas.
- Processamento de pagamentos.

## Retenção e Exclusão de Dados
- Os dados são retidos pelo período necessário para fornecer os serviços.
- Os usuários podem solicitar a exclusão de seus dados a qualquer momento, conforme permitido pela legislação aplicável.

### Gerenciamento de Preferências de Privacidade
Os usuários podem gerenciar suas preferências de privacidade através das configurações de conta em nossa plataforma.
