# Linguagem Ubíqua


---

| Termo                       | Definição                                                                                             |
|-----------------------------|------------------------------------------------------------------------------------------------------|
| **Telemedicina**            | Consultas médicas realizadas remotamente através de videochamadas.                                    |
| **Agendamento de Consultas**| Processo de marcar consultas médicas online através do sistema.                                       |
| **Prontuário Eletrônico**   | Sistema digital para armazenamento e compartilhamento de registros médicos dos pacientes.             |
| **Autenticação de Usuário** | Processo pelo qual médicos e pacientes se identificam no sistema usando credenciais como CRM, e-mail e senha. |
| **Médico**                  | Profissional de saúde registrado no sistema, capaz de agendar, aceitar ou recusar consultas, e acessar prontuários eletrônicos. |
| **Paciente**                | Usuário do sistema que agenda consultas, visualiza horários disponíveis dos médicos e acessa seu prontuário eletrônico. |
| **Horários Disponíveis**    | Intervalos de tempo cadastrados pelos médicos para a realização de consultas.                         |
| **Aceite ou Recusa de Consultas** | Função que permite aos médicos aceitar ou recusar consultas agendadas por pacientes.              |
| **Busca por Médicos**       | Ferramenta que permite aos pacientes encontrar médicos com base em especialidade, distância e avaliação. |
| **Teleconsulta**            | Consulta médica realizada online com duração padrão, gerando um link de reunião para acesso.         |
| **Segurança dos Dados**     | Práticas e medidas implementadas para proteger os dados sensíveis dos pacientes contra acessos não autorizados e violações. |
| **Alta Disponibilidade**    | Garantia de que o sistema estará disponível 24/7, essencial para serviços de saúde críticos.          |
| **Escalabilidade**          | Capacidade do sistema de lidar com um aumento significativo no número de usuários simultâneos, especialmente em horários de pico. |
| **Sistema Proprietário**    | Software desenvolvido e mantido internamente pela Health&Med, diferindo de sistemas de terceiros.     |
