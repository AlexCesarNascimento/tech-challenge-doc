# Processo de Agendamento Médico

## Introdução
Este diagrama representa o processo de agendamento de consultas médicas, desde o login do paciente até a geração do link da reunião. Ele ilustra o fluxo de interações entre pacientes, médicos e o sistema de agendamento.

## Componentes do Diagrama

### Entidades
1. **Paciente**
   - **Descrição**: Representa o paciente que deseja agendar uma consulta.

2. **Médico**
   - **Descrição**: Representa o médico disponível para consultas.

3. **Sistema**
   - **Descrição**: Sistema que gerencia o agendamento de consultas.

### Ações
1. **Login**
   - **Descrição**: Ação onde o paciente realiza o login no sistema.

2. **Verificar Horários Disponíveis**
   - **Descrição**: Ação onde o paciente verifica os horários disponíveis para consulta.

3. **Agendamento**
   - **Descrição**: Ação de agendar a consulta médica.

4. **Consulta**
   - **Descrição**: Ação onde a consulta é realizada.

5. **Geração do Link de Reunião**
   - **Descrição**: Geração do link para a reunião de consulta.

## Fluxo do Processo

1. **Login**
   - O paciente realiza o login no sistema.

2. **Verificar Horários Disponíveis**
   - Após o login, o paciente verifica os horários disponíveis para consulta.

3. **Agendamento**
   - O paciente agenda a consulta com o médico.

4. **Consulta**
   - A consulta é realizada na data e hora agendada.

5. **Geração do Link de Reunião**
   - O sistema gera um link de reunião para a consulta.

## Conclusão
Este diagrama fornece uma visão clara do processo de agendamento de consultas médicas, destacando as interações principais entre pacientes, médicos e o sistema de agendamento. Cada etapa do processo é representada com clareza, permitindo uma compreensão fácil e rápida do fluxo de trabalho.
